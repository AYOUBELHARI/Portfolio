# Café Atlas — Project Brief

## Target users
Local residents and people visiting nearby

## Main user needs
See the menu, check opening hours, find the café and contact it

## Sections
- Header / navigation
- Hero
- Menu highlights
- Opening hours and location
- Contact / footer

## Primary action
View menu

## Secondary action
Get directions

## Acceptance criteria
- [ ] The website works on mobile screens
- [ ] The menu displays item names and prices
- [ ] The contact and directions links work

## Website language
French

## Scope
A responsive, single-page café website built with HTML, CSS and JavaScript. No backend, payment system, customer accounts or online ordering in version one.
